# План разработки WordPress-темы — QAZAQSTAN Resort

Источник правды по WP-части. Дополняет `CLAUDE.md` (бренд, токены, стандарты кода) и ТЗ заказчика. При конфликте: ТЗ → CLAUDE.md → этот файл. Дизайн утверждён по HTML-прототипу — он эталон вёрстки.

---

## 1. Цель переноса

HTML-прототип (18 страниц, Vite + Tailwind) утверждён. Задача — продакшн-тема WordPress, где:

- весь контент (цены, скидки, фото номеров и услуг, тексты, новости) редактирует менеджер из админки **без кода**;
- сайт работает на двух языках **RU (по умолчанию) + KK** с переключателем;
- SEO настроено глубоко (мета, Schema.org, hreflang, sitemap, ЧПУ);
- производительность ≥80 mobile / ≥90 desktop.

Не цель сейчас: онлайн-оплата (фаза 2), EN-версия (фаза 2).

---

## 2. Стек и окружение

| Слой | Решение |
|---|---|
| CMS | WordPress 6.x, PHP 8.2+, MySQL/MariaDB |
| Тема | **Sage 11** (Roots): Blade, Acorn, Vite, Tailwind |
| Локальная разработка | **`@wordpress/env`** (Docker — уже установлен) |
| Тулинг темы | PHP 8.2 + Composer через Homebrew (локально отсутствуют — ставлю) |
| Сборка ассетов | Vite (переносим текущий конфиг), Tailwind 3.4 |
| Хостинг (прод) | Казахстанский: PS.KZ / Hoster.kz, ≥15 ГБ, SSL |

Локальная разработка: `wp-env` поднимает WP + БД + плагины в Docker. Тема монтируется как volume, Vite крутит HMR ассетов. Composer ставит зависимости Sage (`roots/acorn`).

### Решённые технические развилки

- **ACF Free** на старте. Доступ к полям — только через хелперы `qazaqstan_*` в `app/`, чтобы переход на ACF Pro (Options Pages, Flexible Content) не требовал правок шаблонов.
- **Polylang** (бесплатный) для RU/KK. WPML не нужен для двух языков.
- **Yoast SEO Free** для мета/sitemap/Schema/hreflang.
- Формы — **собственный обработчик** на REST + CPT хранилище заявок (см. §8), а не CF7-плагин, чтобы заявки сразу падали в БД и были видны менеджеру.

### Расхождение токенов

В ТЗ хексы бренда (`#387288`, `#559340`) отличаются от утверждённого прототипа и `CLAUDE.md` (`#3872B8`, `#5E9340`). **Берём значения из `CLAUDE.md`/прототипа** — это утверждённый дизайн. Шрифты: H1–H3 Manrope (в ТЗ — Intro; Intro как опциональный апгрейд при наличии лицензии), текст PT Sans, декор Caveat (в ТЗ — Rage Italic; используем то, что в прототипе).

## 3. Архитектура темы (Sage 11)

### 3.0 Размещение в репозитории

Прототип не трогаем — он задеплоен на GitHub Pages как утверждённый эталон дизайна. Раскладка репо:

```text
/ (корень)            HTML-прототип (Vite) — без изменений, деплой на Pages
├── docs/             планы и документация
├── theme/            тема Sage 11 (новая разработка) ← основной деливерабл
├── .wp-env.json      локальный WordPress (Docker), монтирует ./theme
└── ...
```

На казахстанский хостинг уедет только `theme/` (как `wp-content/themes/qazaqstan`) + плагины + дамп БД. wp-env и прототип на прод не идут.

### 3.1 Структура темы

```text
themes/qazaqstan/
├── app/
│   ├── setup.php              регистрация меню, sidebars, supports
│   ├── filters.php
│   ├── helpers.php            qazaqstan_get_field(), qazaqstan_option(), форматтеры цен
│   ├── PostTypes/             Room, Doctor, Procedure, Vacancy, ConferenceHall,
│   │                          Service, Testimonial, Document, BookingRequest, Appeal
│   ├── Taxonomies/            MedicalProfile, RoomType, Amenity, DocType
│   ├── Fields/                ACF-группы в КОДЕ (acf_add_local_field_group)
│   ├── Blocks/                ACF/Gutenberg блоки секций
│   ├── Forms/                 REST-обработчики форм, валидация, уведомления
│   └── Seo/                   Schema.org JSON-LD билдеры
├── resources/
│   ├── views/
│   │   ├── layouts/app.blade.php
│   │   ├── partials/          header, footer, breadcrumbs, lang-switcher, card-*
│   │   ├── blocks/            blade на каждый блок секции
│   │   ├── front-page.blade.php
│   │   ├── page-{slug}.blade.php
│   │   ├── single-{cpt}.blade.php
│   │   └── archive-{cpt}.blade.php
│   ├── styles/                переезд app.css + custom.css
│   ├── scripts/               переезд app.js + modules/ (header, menu, carousel)
│   └── fonts/                 Manrope, PT Sans, Caveat (+ RageItalic если лицензия)
└── public/                    собранные ассеты (gitignore)
```

Принципы: Blade, не PHP-в-шаблонах. Все строки через `__('...', 'qazaqstan')`. Вывод экранируется. Цвета/шрифты — токены. Комментарии в коде не пишем.

## 4. Контент-модель (ядро редактируемости)

Главный принцип: **то, что менеджер меняет часто** → поля ACF на CPT или странице настроек; **то, что структурно повторяется** → CPT; **то, что глобально** (контакты, скидки, аналитика) → страница настроек.

### 4.1 Custom Post Types

| CPT | ЧПУ | Назначение | Ключевые поля (редактирует менеджер) |
|---|---|---|---|
| `room` | `/accommodation/{slug}` | Номера | тип (таксономия), площадь м², вместимость, цена 1-местного, цена 2-местного, удобства (таксономия), галерея, краткое+полное описание, «что включено», флаг «бронируется» |
| `doctor` | `/treatment/doctors/{slug}` | Врачи | ФИО, должность, профиль (таксономия), стаж, фото, регалии, описание |
| `procedure` | `/treatment/{slug}` | Процедуры/методики | профиль (таксономия), описание, показания, длительность, фото |
| `conference_hall` | `/conferences/{slug}` | Конференц-залы | вместимость, площадь, оснащение (repeater), варианты рассадки, цена аренды (час/день), планировка, галерея |
| `service` | `/services/{slug}` | Доп. услуги | иконка/фото, описание, цена/«по запросу», категория |
| `testimonial` | — (не публичный) | Отзывы | автор, текст, рейтинг, фото, дата |
| `vacancy` | `/vacancies/{slug}` | Вакансии | должность, отдел, зарплата, требования (repeater), обязанности (repeater), статус (открыта/закрыта), дедлайн |
| `document` | `/documents/{slug}` | Документы | файл (PDF), тип (таксономия: госзакупки/антикоррупция/лицензии), год, дата публикации |
| `booking_request` | — (приватный) | Заявки на бронь | даты, номер, услуги, гости, контакты, статус (новая/в работе/закрыта) |
| `appeal` | — (приватный) | Обращения | тема, ФИО, контакты, текст, статус |

Блог и новости — на **нативных постах** (`post`), не CPT (лучшая совместимость с Yoast/Polylang). Разделение через категории (см. §7).

### 4.2 Таксономии

| Таксономия | Для CPT | Термины |
|---|---|---|
| `medical_profile` | doctor, procedure | 5 профилей лечения |
| `room_type` | room | стандарт / люкс / президентский |
| `amenity` | room | Wi-Fi, ТВ, холодильник, балкон, кондиционер… |
| `doc_type` | document | госзакупки / антикоррупция / лицензии и сертификаты |
| `category`, `post_tag` | post | Новости / Полезные статьи + теги |

### 4.3 Глобальные настройки (страница «Настройки сайта»)

ACF Pro → Options Page. ACF Free → собственная страница опций (Settings API + ACF-поля на ней) через `qazaqstan_option('key')`. Вкладки:

- **Контакты:** адрес, телефоны (repeater), email, режим работы, координаты карты, реквизиты.
- **Соцсети/мессенджеры:** repeater (тип + ссылка): Instagram, Telegram, WhatsApp, и т.д.
- **Скидки:** repeater (название, %, условие) — пенсионеры ≤10%, сотрудники МВД 20%, пенсионеры МВД 30%. Меняются без кода.
- **Что входит в путёвку:** repeater пунктов.
- **CTA/баннер шапки, текст футера, подписка.**
- **Аналитика:** GTM ID, GA4 ID, Яндекс.Метрика ID (вставляются через GTM).

Цены номеров живут на самих `room` (а не в глобальных опциях) — менеджер меняет цену прямо в карточке номера. Глобально — только прайс лечебных путёвок и скидки.

### 4.4 Переиспользуемые контентные сущности

То, что встречается на нескольких страницах — оформляем как поля/блоки, не дублируя:

- **FAQ** — repeater (вопрос/ответ) как блок секции на любой странице. Источник для Schema `FAQPage`. Нужен на главной, лечении, бронировании, контактах.
- **История (40 лет)** — на странице «О санатории» repeater-таймлайн (год + событие + фото). ТЗ подчёркивает 40-летнюю историю.
- **Лицензии и сертификаты** — CPT `document` (doc_type=лицензии) + блок-витрина на «О санатории» (превью PDF/изображения).
- **Цифры/достижения** — repeater (число + подпись): коек, профилей лечения, лет, гостей в год.
- **Преимущества/УТП** — repeater (иконка + заголовок + текст) для блоков «почему мы».
- **Расписание** (спорткомплекс, бассейн) — repeater (день/время/сеанс) + правила.
- **CTA-блок** — переиспользуемый призыв «забронировать/позвонить» в конце страниц.

### 4.5 Медиа

- **Галерея** поддерживает фото **и видео** (ТЗ требует видео территории), с категориями-фильтрами: территория, номера, процедурные кабинеты, мероприятия.
- **Hero-видео** на главной — загружаемое (poster + `preload=metadata`, без autoplay на mobile).
- **Favicon** — загружается в настройках сайта (ТЗ: добавление фавикона).
- Все изображения — обязательный alt, авто-`srcset` + WebP/AVIF, lazy-load.

## 6. Многоязычность (Polylang, RU + KK)

- Языки: **RU — дефолтный без префикса**, **KK — `/kk/`**.
- Переводится: страницы, посты, все CPT, термины таксономий, меню.
- Строки темы (`__()`) — через .po/.mo (Loco Translate) или Polylang String Translations.
- ACF-поля: включить перевод групп; глобальные опции дублируются по языкам.
- Переключатель RU/KK в шапке (заменяет статичные кнопки прототипа) — выводит ссылку на текущую страницу в другом языке.
- hreflang — автоматически Polylang + Yoast (`ru-RU`, `kk-KZ`, `x-default`).
- Язык KK — **кириллица** (локаль `kk_KZ`). Сам контент — на кириллице. Латиницей остаются **только slug'и в URL** (транслит, по правилу ЧПУ), не текст.

Контент заказчик предоставляет на двух языках (текст ТЗ уже двуязычный — хороший знак).

## 7. Блог и новости

Нативные посты, две рубрики:

- **Новости** (`news`) — события санатория, анонсы.
- **Полезные статьи** (`articles`) — про здоровье, лечение (важно для SEO-ключей).

Поля поста: featured image (обязательно, с alt), excerpt (ручной), категория, теги, автор, дата. Шаблон single: оглавление по H2 (если длинный), время чтения, шаринг в соцсети, блок «похожие статьи» (по категории/тегам), хлебные крошки, Schema `Article`/`NewsArticle`. Архив `/blog/` — фильтр по рубрике, пагинация, sidebar с популярным.

SEO-ключи статей завязываем на список из ТЗ (санаторно-курортное лечение, медицинская реабилитация, ЛФК, СПА в Алматы и т.д.).

## 8. Формы и заявки

Все формы: nonce + honeypot + reCAPTCHA v3 + серверная валидация + запись в БД (CPT) + email менеджеру. Обработчик — REST-эндпоинт темы (`/wp-json/qazaqstan/v1/...`), без тяжёлого плагина.

| Форма | Хранилище | Поля |
|---|---|---|
| **Бронирование (5 шагов)** | CPT `booking_request` | даты заезда/выезда, тип номера (из room), доп. услуги, кол-во гостей, имя, телефон, email, комментарий |
| **Обращение** | CPT `appeal` | тема (селектор: Президенту АО / Сотрудничество / Жалоба / Общий вопрос), ФИО, контакты, текст, вложение |
| **Заказать звонок** | CPT `appeal` (тип=callback) | имя, телефон, удобное время |
| **Подписка (footer)** | таблица/интеграция рассылки | email |

Заявки видны в админке как обычные записи с колонками (дата, статус, контакт), менеджер меняет статус. Уведомления: email обязательно; Telegram-бот/WhatsApp — опционально (фаза 1.5). Онлайн-оплата (Kaspi Travel) — **фаза 2**.

## 9. SEO

- **Технически:** ЧПУ, `robots.txt`, XML-sitemap (Yoast), кэш/сжатие/минификация (§10).
- **Мета:** Title/Description редактируемы на каждой странице (Yoast). Шаблоны мета по типам.
- **Schema.org (JSON-LD, билдеры в `app/Seo/`):** `LodgingBusiness`/`Hotel` (организация), `MedicalBusiness`, `Room` (номера), `Article`/`NewsArticle` (блог), `BreadcrumbList`, `FAQPage` (где есть FAQ), `JobPosting` (вакансии).
- **OG + Twitter Cards**, canonical, hreflang RU/KK.
- Один H1 на страницу, семантика H2–H6, alt у всех изображений, хлебные крошки.
- Аналитика: GTM-контейнер → GA4 + Яндекс.Метрика (ID в опциях).
